# Google Form Setup - BLKOUT CBS Founding Members Affiliations Confirmation

## Purpose

Create an easy-to-use Google Form that allows founding members to confirm their organizational affiliations with just a few clicks, instead of replying to emails.

---

## Option 1: Single Form with Member Selection (RECOMMENDED)

This approach uses ONE Google Form that all members can use, with conditional logic to show each member their specific findings.

### How to Create

1. Go to **Google Forms**: https://forms.google.com
2. Click **+ Blank** to create a new form
3. Title: **BLKOUT CBS - Member Affiliations Confirmation (FCA Requirement)**
4. Description:
   ```
   The FCA has requested confirmation of organizational affiliations for all BLKOUT
   founding members. Please confirm the findings below and add any roles we may have
   missed. This should take less than 2 minutes.

   FCA deadline: [INSERT DATE]
   ```

## Setting Up Conditional Logic (CRITICAL)

Google Forms can show different sections based on Question 1 answer:

1. Click on Question 1 (member name dropdown)
2. Click the three dots menu (⋮) in the bottom right
3. Select **"Go to section based on answer"**
4. For each member name, select the corresponding section:
   - Jean-Eric Nkurikiye → Section 2
   - Lloyd Young → Section 3
   - Nathan Lewis → Section 4
   - Olamide Adesanya → Section 5
   - Peter Fleming → Section 6
   - Reuben Silungwe → Section 7
   - Cardew Jackson-Cole → Section 8
   - Gerrard Martin → Section 9

This ensures each member only sees their own findings, making the form quick and personalized.

## Form Settings

**General Settings:**
1. Click **Settings** (gear icon in top right)
2. Under **General**:
   - ✅ Limit to 1 response (optional - prevents duplicate submissions)
   - ✅ Collect email addresses
3. Under **Presentation**:
   - ✅ Show progress bar
   - Confirmation message: (see above)
4. Under **Quizzes**:
   - Leave as **Not a quiz**

**Sharing:**
1. Click **Send** button
2. Get shareable link
3. Shorten URL using bit.ly or similar (makes emails cleaner)
4. Include link in each email as "Option 3"

## Option 2: Individual Forms per Member (Alternative)

If you prefer, you can create 8 separate forms (one per member) with pre-filled information. This makes each form even simpler but requires managing 8 different links.

**Pros:**
- Shortest possible form for each member (no name selection needed)
- Can pre-fill their name and email
- Impossible for members to accidentally select wrong name

**Cons:**
- Need to manage 8 different forms
- 8 different response spreadsheets (unless you manually consolidate)

**How to do it:**
1. Create the first form for Jean-Eric
2. Duplicate it 7 times
3. Edit each form to show only that member's findings
4. Send each member their unique form link

---

## Response Management

**Viewing Responses:**
1. In your Google Form, click the **Responses** tab
2. Click the Google Sheets icon to create a spreadsheet with all responses
3. Responses will appear in real-time as members submit

**Response Spreadsheet Columns:**
- Timestamp
- Member Name
- Email
- Confirmation answer
- Additional/corrected information
- Any other fields

**What to do with responses:**
1. Review each submission
2. Update `MASTER_AFFILIATIONS_SPREADSHEET.md` with any corrections/additions
3. Update `FCA_RESPONSE_LETTER_DRAFT.md` if needed
4. Track who has responded (see tracking guide in `SENDING_GUIDE.md`)
